This repository contains data, intended for reproducibility of a relevant research paper about multilingual claim decomposition. Its contents include the code, used for performing decomposition as well as the code of two-level evaluation procedure, used to assess the decomposition quality. The data directory contains a dataset used in the relevant study with ClaimID, ClusterID, and Language, taken from the original MultiClaim dataset from the MultiClaimNet collection. The remaining fields can be accessed using the original dataset.
